# Citation ledger

**Every number and every requirement in this project traces to a row in this file.**

This is hard boundary #4 made operational. Fabricated regulatory content is the single
fastest way to lose this project, and a plausible-looking invented statute number is worse
than an honest blank.

## The rule

> If you cannot point at an actual source document, the entry is marked `"verified": false`
> and the UI surfaces it as unverified. **Do not guess a citation.** An unverified
> requirement is a known gap. A fabricated one is a lie a judge may catch on stage.
