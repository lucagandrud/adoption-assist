# Citation ledger

**Every number and every requirement in this project traces to a row in this file.**

This is hard boundary #4 made operational. Fabricated regulatory content is the single
fastest way to lose this project, and a plausible-looking invented statute number is worse
than an honest blank.

## The rule

> If you cannot point at an actual source document, the entry is marked `"verified": false`
> and the UI surfaces it as unverified. **Do not guess a citation.** An unverified
> requirement is a known gap. A fabricated one is a lie a judge may catch on stage.

## Where to look

Starting points for sourcing CA and TX requirement data. **Verify current versions** —
regulatory text changes and a superseded citation is a defect.

- **AAICPC** (Association of Administrators of the ICPC) — ICPC regulations and the
  ICPC-100A/100B forms
- **California CDSS** — Resource Family Approval written directives and all-county letters
- **Texas DFPS** — home screening, licensing standards, and the Texas Administrative Code
  chapters they implement
- **Child Welfare Information Gateway** (federal) — state statute summaries, useful for
  orientation but **cite the underlying state document, not the summary**
